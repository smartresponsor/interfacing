# Interfacing service contracts

This directory contains service contracts for the Interfacing component. New contracts should use capability-specific folders when the vocabulary is narrower than the whole component, for example `Crud/`, `View/`, `Catalog/`, `Shell/`, `Access/`, `Runtime/`, or `Provider/`. Root-level aliases are not a growth path. New contracts must live in capability-specific folders; deprecated access/action aliases were retired in the Wave 8 cleanup.
